# RAG - Projet d'apprentissage

Ceci est un projet d'exemple pour apprendre à construire un système Retrieval-Augmented Generation (RAG) from scratch.

## Objectifs

- Implémenter un pipeline simple de RAG en Python
- Documenter l'apprentissage et les décisions dans `notes/learning.md`
- Publier une présentation conviviale via GitHub Pages (dossier `docs/`)

## Structure initiale

- `docs/` : contenu GitHub Pages
- `notes/` : prises de notes et journaux d'apprentissage
- `requirements.txt` : dépendances Python

## Démarrage

1. Installer les dépendances:

```
pip install -r requirements.txt
```

2. Lire `notes/learning.md` pour le plan d'apprentissage.

## Déploiement GitHub Pages

La page GitHub Pages sera servie depuis le dossier `docs/`.
