# Journal d'apprentissage

Bienvenue dans le journal d'apprentissage pour ce projet RAG.

## But

Noter ce que j'apprends, les décisions techniques et les questions ouvertes.

## Template d'une entrée
- **Date :** YYYY-MM-DD
- **Sujet :** bref titre
- **Ce que j'ai fait :** étapes effectuées
- **Ce que j'ai compris :** résumé
- **Prochaines étapes :** actions suivantes

## Exemple
- **Date :** 2026-05-10
- **Sujet :** Initialisation du projet
- **Ce que j'ai fait :** Initialisé repo, ajouté README et page docs
- **Ce que j'ai compris :** Structure minimale pour RAG et route vers GitHub Pages
- **Prochaines étapes :** implémenter indexation et retrieval
